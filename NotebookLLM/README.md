# Diretório de Conversas e Ideias do NotebookLM
**Fonte de Origem:** [Micheline Sanabio Machado System Profile Directory - Gemini Notebook](https://notebook.google.com/notebook/7e7d73b8-3d8c-423c-9424-9a39fb0f8c9a)

---

## Propósito
Este diretório armazena todas as conversas, notas conceituais, especificações de perfil de sistema e ideias quantitativas extraídas do Gemini Notebook de Micheline Sanabio Machado para futura implementação na arquitetura do `Automatizar_ETH`.

## Estrutura Recomendada de Nomenclatura dos Arquivos
Os arquivos neste diretório devem seguir títulos semânticos padronizados que identifiquem claramente o tema abordado:

- `01_perfil_sistema_micheline_sanabio.md`: Diretrizes estruturais, identidade e premissas operacionais do sistema.
- `02_regras_monitoramento_quant_ordens.md`: Especificações matemáticas das ordens limites e confluências técnicas.
- `03_radar_onchain_fluxo_protocolo.md`: Análise de net issuance, queima EIP-1559, blob gas e staking.
- `04_modelos_valuation_ciclo_eth.md`: Metodologias de MVRV Z-Score, múltiplos de TVL e bandas ETH/BTC.
- `05_estrategias_alertas_telegram_risco.md`: Lógica de histerese, proximidade crítica e mitigação de spoofing.
